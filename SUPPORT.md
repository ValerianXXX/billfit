# BillFit Support

Use GitHub Issues for public support:

https://github.com/ValerianXXX/billfit/issues

When reporting a problem, include the BillFit version, operating system, Python version, calculation operation, expected behavior, and sanitized error message.

Do not include utility credentials, account numbers, full bills, interval-usage files, income documents, medical information, tax records, or other personal data. If a minimal synthetic example can reproduce the problem, use that instead.

BillFit does not provide emergency assistance, utility-account support, enrollment decisions, or medical certification. Contact PG&E or the relevant public agency for those matters.
